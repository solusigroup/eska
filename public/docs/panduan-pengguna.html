📁 Master Data

Pelanggan

Mengelola data pelanggan/customer perusahaan.

  • Tambah Pelanggan: Menu Pelanggan → Tambah Baru
  • Isi nama, alamat, telepon, email, dan saldo awal piutang
  • Klik Simpan

Pemasok

Mengelola data supplier/vendor perusahaan.

  • Tambah Pemasok: Menu Pemasok → Tambah Baru
  • Isi nama, alamat, telepon, email, dan saldo awal hutang
  • Klik Simpan

Persediaan/Barang

Mengelola data barang dagangan.

Field Keterangan
Kode Barang Kode unik untuk identifikasi barang
Nama Barang Nama/deskripsi barang
Satuan Unit (pcs, kg, liter, dll)
Harga Beli Harga pembelian dari supplier
Harga Jual Harga jual ke pelanggan
Stok Awal Jumlah stok awal periode

Akun (Chart of Accounts)

Mengelola daftar akun untuk pencatatan jurnal.

Tipe Akun Kode Contoh
Kas & Bank 1-1xxx Kas, Bank BCA, Bank Mandiri
Piutang 1-2xxx Piutang Usaha, Piutang Karyawan
Persediaan 1-3xxx Persediaan Barang Dagang
Aset Tetap 1-5xxx Kendaraan, Peralatan
Kewajiban 2-xxxx Utang Usaha, Utang Bank
Modal/Ekuitas 3-xxxx Modal Disetor, Laba Ditahan
Pendapatan 4-xxxx Penjualan, Pendapatan Jasa
HPP 5-xxxx Harga Pokok Penjualan
Beban 6-xxxx Beban Gaji, Beban Listrik

💰 Transaksi

Penjualan

  1. Buka menu Penjualan → Tambah Baru
  2. Pilih Pelanggan dari daftar
  3. Isi No. Faktur dan Tanggal
  4. Tambahkan item barang yang dijual (kuantitas × harga)
  5. Pilih Metode Pembayaran:
    • Tunai: Pembayaran langsung, pilih akun Kas/Bank
    • Kredit: Menjadi piutang ke pelanggan
  6. Isi keterangan jika perlu
  7. Klik Simpan
✓ Otomatis: Sistem akan otomatis membuat jurnal akuntansi dan mengupdate stok barang.

Pembelian

  1. Buka menu Pembelian → Tambah Baru
  2. Pilih Pemasok dari daftar
  3. Isi No. Faktur Pembelian dan Tanggal
  4. Tambahkan item barang yang dibeli
  5. Pilih Metode Pembayaran:
    • Tunai: Pembayaran langsung dari Kas/Bank
    • Kredit: Menjadi hutang ke pemasok
  6. Klik Simpan

Penerimaan Pembayaran

Untuk mencatat pembayaran piutang dari pelanggan:

  1. Menu Penerimaan → Tambah Baru
  2. Pilih Pelanggan yang membayar
  3. Pilih Faktur yang akan dilunasi
  4. Masukkan Jumlah Bayar
  5. Pilih Akun Kas/Bank penerima
  6. Klik Simpan

Pembayaran Hutang

Untuk mencatat pembayaran hutang ke pemasok:

  1. Menu Pembayaran → Tambah Baru
  2. Pilih Pemasok yang akan dibayar
  3. Pilih Faktur Pembelian yang akan dilunasi
  4. Masukkan Jumlah Bayar
  5. Pilih Akun Kas/Bank pembayar
  6. Klik Simpan

📒 Jurnal & Kas

Jurnal Umum

Untuk mencatat transaksi yang tidak tercover oleh modul lain:

  1. Menu Jurnal → Tambah Baru
  2. Isi No. Transaksi, Tanggal, dan Deskripsi
  3. Tambahkan baris jurnal:
    • Pilih Akun
    • Isi Debit atau Kredit
  4. Pastikan Total Debit = Total Kredit
  5. Klik Simpan
⚠️ Penting: Jurnal harus balance (Debit = Kredit) agar bisa disimpan.

Jurnal Kas

Pencatatan cepat untuk transaksi kas masuk dan keluar:

Tipe Contoh Penggunaan
Kas Masuk Pendapatan lain-lain, bunga bank, dll
Kas Keluar Beban operasional, biaya lain-lain

Transfer Antar Kas/Bank

Menu Kas → Transfer untuk memindahkan dana antar rekening.

📊 Laporan Keuangan

Buku Besar

Melihat mutasi semua akun dalam periode tertentu.

  • Pilih Akun yang ingin dilihat
  • Tentukan Periode (tanggal awal - akhir)
  • Klik Tampilkan

Neraca

Laporan posisi keuangan (Aset = Kewajiban + Ekuitas)

  • Pilih Tanggal neraca
  • Klik Tampilkan atau Export PDF

Laba Rugi

Laporan kinerja keuangan (Pendapatan - Beban = Laba/Rugi)

  • Laba Rugi Umum
  • Laba Rugi per Proyek
  • Laba Rugi Konsolidasi

Arus Kas

Laporan pergerakan kas perusahaan:

  • Metode Langsung: Berdasarkan penerimaan dan pengeluaran kas aktual
  • Metode Tidak Langsung: Rekonsiliasi dari laba bersih
  • Per Proyek: Arus kas untuk proyek tertentu

Laporan Perubahan Ekuitas

Perubahan modal pemilik selama periode.

Laporan Persediaan

Daftar barang beserta stok dan nilai persediaan.

🏗️ Manajemen Proyek

Membuat Proyek Baru

  1. Menu Proyek → Tambah Baru
  2. Isi data proyek:
    • Kode Proyek (unik)
    • Nama Proyek
    • Deskripsi
    • Tanggal Mulai & Selesai
    • Anggaran
    • Lokasi
    • Pelanggan
  3. Klik Simpan

Assign Transaksi ke Proyek

Setiap transaksi (Penjualan, Pembelian, Jurnal Kas) dapat di-assign ke proyek tertentu untuk tracking biaya dan pendapatan per proyek.

Status Proyek

Status Keterangan
Aktif Proyek sedang berjalan
Selesai Proyek sudah complete
Ditunda Proyek di-hold sementara

📤 Import & Export Data

Export Data

Menu Import/Export → pilih modul → Export Excel

Modul yang bisa di-export:

  • Pelanggan
  • Pemasok
  • Persediaan/Barang
  • Akun (COA)

Import Data

  1. Download Template terlebih dahulu
  2. Isi data sesuai format template
  3. Upload file Excel
  4. Review data yang akan di-import
  5. Klik Import

Import Jurnal Kas

Untuk import transaksi kas dari file Excel (misal: dari rekening koran):

  1. Menu Import Kas
  2. Upload file Excel dengan kolom: Tanggal, Uraian, Uang Masuk, Uang Keluar
  3. Review dan mapping akun
  4. Pilih transaksi yang ingin diposting
  5. Klik Post

⚙️ Pengaturan

Data Perusahaan

Menu Perusahaan untuk mengatur:

  • Nama Perusahaan
  • Alamat, Telepon, Email
  • Jenis Usaha (Dagang/Jasa/Konstruksi)
  • Akun Default Piutang & Hutang
  • Nama Direktur & Akuntan (untuk laporan)

Manajemen User

Menu Users untuk mengelola pengguna sistem.

  1. Klik Tambah User
  2. Isi Nama User, Password, Role, dan Jabatan
  3. Klik Simpan

Database Management

⚠️ Hanya Superuser! Menu ini hanya untuk administrasi database. Gunakan dengan hati-hati!
  • Truncate: Kosongkan data transaksi
  • Fresh: Reset database ke kondisi awal
  • Seed: Isi data contoh
